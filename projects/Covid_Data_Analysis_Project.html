COVID-19 data analysis with SQL

How did reported COVID-19 cases and deaths change in the UK, and how did vaccine rollout vary across countries? This project uses SQLite queries in a Python notebook to explore daily records from 1 January 2020 to 30 April 2021. Each source CSV contains 85,171 rows and includes both individual locations and regional aggregates.

Explore the analysis notebook

A finding from the UK analysis

By 30 April 2021, the UK had recorded 4,432,246 cases and 127,775 deaths. Reported deaths amounted to 2.88% of reported cases at that point. This ratio depends on which infections were detected and on the delay between a case and a death.

What the notebook explores

  • UK trends. Calculate reported deaths as a percentage of reported cases, and reported cases as a share of the population.
  • Geographic comparisons. Rank locations by reported cases relative to population and compare cumulative death counts. The continent query takes the highest country death count within each continent. A continent-wide total would require summing country counts for a common date.
  • Global trends. Aggregate new cases and deaths by day, excluding rows that already represent geographic totals.
  • Vaccination rollout. Join the two datasets by location and date. Use a window function to accumulate reported daily doses within each location, then save the query as a reusable SQLite view.

Repository files

File Purpose
covid_analysis.ipynb SQL analysis, query results and Python code for loading the data
CovidDeaths.csv Daily case and death records with population figures
CovidVaccinations.csv Daily vaccination records and related indicators
covid.db SQLite database with both source tables and the saved vaccination queries

Run in GitHub Codespaces

  1. Open this repository in a Codespace. From the repository root, run the following in the terminal:

    python3 -m venv .venv
source .venv/bin/activate
python -m pip install pandas ipykernel

  2. Open covid_analysis.ipynb, choose Select Kernel, and select the Python interpreter in .venv.

  3. Run the cells from top to bottom. The first cell rebuilds the two source tables from the CSVs. To explore the included database directly, start at the second cell, which opens covid.db.

Use the vaccination data in Tableau

The vaccination_trends view handles the CSVs’ day/month/year dates in chronological order. Use this view for time-series charts. Some earlier practice queries sort the original date strings alphabetically.

To export the view, run this in a notebook cell after opening the database:

trends = pd.read_sql_query("SELECT * FROM vaccination_trends", db)
trends["date"] = pd.to_datetime(trends["date"], format="%d/%m/%Y")
trends.to_csv("vaccination_trends.csv", index=False, date_format="%Y-%m-%d")

Download the resulting CSV and open it in Tableau as a Text File. For a UK rollout chart, filter location to United Kingdom, place date on Columns and rolling_doses on Rows. Use the daily date level. The view accumulates doses on days with a reported value, and an individual can contribute more than one dose.
