🧪 Acrylamide synthesis by the numbers

What changes when you call the same chemical by two different names? In a spreadsheet, it can end up competing with itself. This Python notebook tackles that problem before counting which reagents and solvents appear most often in Reaxys records of acrylamide synthesis from 2000 to 2025.

Open the notebook and explore the charts →

The charts are saved in the notebook, so you can browse the results on GitHub without running any code.

From 12,155 records to two reactant groups

The dataset covers journal articles and patents. The notebook splits chemical lists into individual entries, keeps records with two listed reactants, and standardises names. For example, it groups “acrylic acid chloride” with “acryloyl chloride” so both names count towards the same group.

Checkpoint Rows in the saved run

Distinct rows mentioning acrylic acid as a reactant 824

Reading the counts. The charts count mentions in the filtered records. A record can list several chemicals, and the plotting cells retain duplicate rows. The 824-row figure above counts distinct rows. The chart totals therefore answer a different question from the subset summary.

Run it yourself

  1. Place the notebook and both input files in the same folder. The filenames are case-sensitive.

    Input file What it contains
    reaction_data_2000_2025.csv Reaxys export with the original column names, including Year, Reactant, Reagent and Solvent (Reaction Details)
    Solvent_List.txt Tab-separated lookup file with a header row, solvent name in the first column and preferred IUPAC name in the second

  2. In a Python environment, open a terminal in that folder and run these commands.

    python -m pip install jupyterlab pandas matplotlib numpy pubchempy
python -m jupyterlab Acrylamide_Synthesis_ETL_Pipeline.ipynb

  3. In JupyterLab, choose Run → Run All Cells. The notebook displays the charts inline and writes two files in the working folder.

    • cleaned_dataset.csv contains the filtered records with standardised names and classified reagent columns.
    • coupling_reagent_bar_plot_data.csv contains the data behind the top-eight coupling reagent chart.

Running the notebook again overwrites these two CSV files.
